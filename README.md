# pontoon

This is a library (and a CLI tool) that generates OpenAPI 3.1 documentation for Go services.

It generates the OpenAPI spec from Go structs annotated with [httpin](https://github.com/ggicci/httpin) tags.  
[docgen](https://github.com/utrack/pontoon/docgen) ([CLI](https://github.com/utrack/pontoon/cmd/docgen)) extracts the documentation from the Go code at a compile time; and in the runtime, [docmerge](https://github.com/utrack/pontoon/openapi/docmerge) merges it with the OpenAPI spec generated by [httpinmeditate](https://github.com/utrack/pontoon/openapi/httpinmeditate).

The runtime part of this library is meant to be integrated with the router library of your choice, or it can be used with the raw http server.  
See the raw HTTP server usage example at [/examples/petstore](https://github.com/utrack/pontoon/blob/runtime-docs/examples/petstore/openapi.go#L11).
